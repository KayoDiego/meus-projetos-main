# 📄 Repositório: Meus Projetos

Este repositório reúne vários projetos pessoais desenvolvidos para estudo, prática e exploração de diferentes tecnologias no front-end e back-end.


## 📖 Projetos Incluídos

Os diretórios contidos neste repositório contém:

* Paginas HTML/CSS simples
* Projetos com JavaScript puro
* Testes com APIs
* Projetos com foco em responsividade
* Exemplos de componentes front-end

## 🌐 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Outros recursos conforme cada projeto

## 📚 Como usar

1. Clone o repositório:

   ```bash
   git clone https://github.com/KayoDiego/meus-projetos-main.git
   ```

2. Acesse a pasta desejada:

   ```bash
   cd Meus-Projetos-main/Meus-Projetos-main
   ```

3. Abra o arquivo `index.html` do projeto escolhido com seu navegador.


## 🎓 Aprendizados

* Prática constante de HTML, CSS e JavaScript
* Organização de projetos em pastas
* Evolução pessoal em lógica e design web
